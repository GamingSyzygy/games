# Galaxy Raiders

Arcade space shooter that runs in the browser from a single `index.html`.

**Play:** https://gamingsyzygy.github.io/games/galaxy-raiders/

## Controls

| Action | Keys |
|---|---|
| Move | Left / Right arrows, or A / D |
| Fire | Space or Up arrow |
| Laser | Down arrow, Z, X, N or M |
| Toggle hard mode (title screen) | Left / Right arrows |

## Running locally

Open `index.html` in a modern browser. No build step or server is needed.
